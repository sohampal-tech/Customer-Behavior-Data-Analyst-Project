# 🛒 Customer Behavior Data Analyst Project

## 📌 Project Overview
This project focuses on analyzing customer shopping behavior using transactional data collected from 3,900 purchases across multiple product categories. The analysis aims to identify valuable insights related to customer spending habits, purchasing trends, product preferences, and subscription behavior.
The complete workflow includes:

- Data Collection
- Data Cleaning & Preprocessing using Python
- Exploratory Data Analysis (EDA)
- SQL-based Data Analysis
- Interactive Dashboard Development in Power BI
- Business Insights & Recommendations

The project helps businesses make data-driven decisions by understanding customer trends and improving overall customer experience.

## 📊 Project Workflow

### 1️⃣ Business Problem Statement
A leading retail company wants to better understand its customers’ shopping behavior in order to improve sales, customer satisfaction, and long-term loyalty. The management team has noticed changes in purchasing patterns across demographics, product categories, and sales channels (online vs. offline). They are particularly interested in uncovering which factors, such as discounts, reviews, seasons, or payment preferences, drive consumer decisions and repeat purchases.

The company aims to use data-driven insights to identify trends, optimize marketing strategies, improve customer engagement, and enhance product performance. By analyzing consumer behavior data, the organization seeks to make smarter business decisions that increase profitability and strengthen customer relationships.

“How can the company leverage consumer shopping data to identify trends, improve customer engagement, and optimize marketing and product strategies?”

### 2️⃣ Data Modeling & EDA in Python
- Data Cleaning
- Handling Missing Values
- Exploratory Data Analysis
- Data Visualization

### 3️⃣ Data Analysis using SQL
- Import dataset into SQL database
- Perform business-driven SQL analysis
- Extract customer insights

### 4️⃣ Interactive Dashboard using Power BI
- KPI Visualization
- Customer Segmentation
- Sales & Revenue Analysis
- Interactive Reports

### 5️⃣ Business Insights & Recommendations
Summarizing findings and providing actionable business recommendations.
